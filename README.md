## 콘텐츠 수정하기

대부분의 문구와 데이터는 `assets/js/data.js` 한 파일에 모여 있습니다.

| 대상 | 위치 |
|---|---|
| 공지사항 · 커뮤니티 · 매거진 · 굿즈 | `SEED` |
| 메인스테이지 출연진 | `LINEUP` |
| 치어 · 회유 · 회귀 · 산란 4단계 | `STAGES` |
| 당일 진행 타임라인 | `DAY` |
| 21년 연혁 | `HISTORY` |
| 부스 모집 분야 · 스토리존 | `BOOTH_FIELDS` · `BOOTH_ZONES` |
| 부스 신청 구글 폼 주소 | `BOOTH_FORM` |
| 챗봇 응답 | `FAQ` (`k` = 인식 키워드, `a` = 답변) |
| 챗봇 추천 질문 | `QUICK` |
| 100인의 연어 | `P100` |

출연진 사진을 바꾸려면 `assets/img/` 의 파일을 같은 이름으로 교체하면 됩니다.

## 배포 (GitHub Pages)

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / 폴더 `/ (root)` → Save
4. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다

### ghmf.kr 도메인 연결

1. 이 저장소 루트에 `CNAME` 파일을 만들고 내용을 `ghmf.kr` 한 줄로 저장
2. 도메인 등록기관 DNS에 아래 A 레코드 4개를 추가

   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```

   `www.ghmf.kr` 도 쓰려면 CNAME 레코드로 `<계정>.github.io` 를 가리키게 합니다
3. Settings → Pages → Custom domain 에 `ghmf.kr` 입력 후 저장
4. DNS 전파(최대 24시간) 후 **Enforce HTTPS** 체크

## 알아둘 점

- **관리자 페이지 저장은 브라우저에만 남습니다.** `localStorage` 기반이라 글을 올려도 그 브라우저에서만 보입니다. 여러 사람이 함께 쓰려면 서버 DB와 로그인 인증을 붙여야 합니다. 그 전까지는 `data.js` 의 `SEED` 를 직접 고치는 방식이 확실합니다.
- **커뮤니티 글쓰기와 결제는 연결되어 있지 않습니다.** 화면만 있는 상태입니다.
- **연어갤러리와 연어상점 이미지는 자리표시입니다.** 원본 사진으로 교체해야 합니다.
- 배경의 거친 질감은 이미지가 아니라 `app.js` 의 `paint()` 가 캔버스에 매번 그립니다. 포스터 3색(오렌지 `#ED6C0D` · 그린 `#143C24` · 퍼플 `#511B86`)을 그대로 씁니다.
